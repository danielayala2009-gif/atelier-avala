ATELIER AYALA v4.1 — COMPLETE 44-RECORD CULINARY ATLAS

Upload ALL 12 files in this folder to the ROOT of the atelier-avala GitHub repository.

This repaired package combines:
- 4 fully developed Atelier Ayala original recipes with photography
- 40 recovered French pastry training titles from archive.json
- 44 total searchable and clickable archive records

The 40 training records preserve the recovered index faithfully. Their original linked formula pages were not present in the source upload, so the site clearly labels them as recovery records instead of inventing ingredients or methods.

What changed from v3:
- Real pastry photography on the recipe cards
- A visual, map-like France pastry atlas with clickable regional markers
- Clickable Pâte Sucrée and other reusable recipe components
- A dedicated clickable Techniques library
- Cross-links: Recipe → Component → Technique → Place → Recipe
- Complete archive-card tabs for ingredients, method, notes and connections
- Mobile-first / Android PWA layout with the existing burgundy-and-gold app icon
- Offline cache bumped to v4.1 and now includes archive.json so Android does not keep serving the four-recipe-only site

IMPORTANT: after GitHub Pages deploys, refresh the Mac page. On Android, fully close and reopen Atelier Ayala. If the installed app still shows v3, uninstall/reinstall once so the v4 service worker and assets are fresh.
